# PROJETO 1 - Diretrizes, Requisitos e Critérios Avaliativos

## 1. Objetivo e Tecnologia
* Tecnologia obrigatória: React Native com Expo.
* O sistema deve permitir cadastrar, consultar, alterar e remover informações, mantendo os dados salvos no dispositivo mesmo após o fechamento do aplicativo.

## 2. Requisitos Funcionais
* RF01: CRUD completo: adicionar, listar, editar e excluir registros da entidade principal.
* RF02: Persistência local: os dados devem permanecer após fechar e reabrir o app.
* RF03: Listagem inteligente: pelo menos uma forma de busca, filtro ou ordenação.
* RF04: Validação: campos obrigatórios e formatos validados no formulário.
* RF05: Navegação: no mínimo as telas de listagem, formulário e detalhe (Expo Router).
* RF06: Feedback: confirmações de exclusão e mensagens de erro/sucesso ao usuário.

## 3. Requisitos Técnicos
* RT01: React Native com Expo, executável via Expo Go ou build de desenvolvimento.
* RT02: Persistência local à escolha do aluno (AsyncStorage, SQLite, etc.).
* RT03: Código versionado em Git, com commits frequentes.
* RT04: Organização mínima de estrutura: telas, componentes e camada de dados separados.
* RT05: Execução em Android físico ou emulador.

## 4. Itens Opcionais (Pontuação Extra)
* Tema claro/escuro.
* Gráficos ou estatísticas simples dos dados.
* Exportação de dados.
* Notificações locais ou lembretes.
